
# Streamlit Program Metrics – Preview (Fancy Cards + Dark/Light)

## Quick Start
1. Install Streamlit:
   ```bash
   pip install streamlit
   ```
2. Run the app:
   ```bash
   streamlit run app.py
   ```

## What's New
- Two colorful gradient cards with hover effects and subtle animation.
- Sidebar toggle: Light or Dark appearance.
- Same two-card layout on every program page.
- Clean baseline for future: completed vs expected toggle, targets, charts, and data connectors.
